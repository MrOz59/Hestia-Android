# Product names and compatibility

Use **Hestia** in client-facing resource text. Host instructions should mention **Hermes** where its existing Apollo-compatible features apply, while keeping Apollo and Sunshine recognizable as supported hosts.

Keep resource keys, Java package/class names, protocol identifiers, preferences, and Android application IDs stable in a text-only branding change. Keep upstream services, tools, license notices, and historical references named accurately. The Moonlight Internet Hosting Tool is an upstream tool, not a separate Hestia or Artemis product.
